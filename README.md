# Spring Testing App

Приложение для проведения опросов на Spring Shell. Вопросы загружаются из CSV
(`questions_%s.csv`), язык задаётся настройкой `application.locale` (`en` / `ru`).

## Запуск

Нужен настоящий терминал (cmd, Windows Terminal, вкладка Terminal в IntelliJ IDEA).

```
mvn spring-boot:run
```

После старта появится приглашение:

```
shell:>
```

## Команды

| Команда  | Ключ   | Что делает                                                                  |
|----------|--------|-----------------------------------------------------------------------------|
| `list`    | `list`  | Показать все вопросы из CSV в текущей локали (заголовок + текст вопроса + варианты ответов). |
| `run`     | `run`   | Провести опрос: пользователь вводит имя и фамилию, отвечает на все вопросы, выводится результат и вердикт «зачёт/незачёт» (порог из `application.test.pass-threshold`). |
| `help`    | —       | Встроенная команда Spring Shell — список доступных команд.                  |
| `exit`    | —       | Встроенная команда Spring Shell — выйти из шелла.                            |
